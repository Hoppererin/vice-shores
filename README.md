Vice Shores is an original top-down 2D open-world crime game in the spirit of GTA 6: Rico Vega drives, steals cars, dodges the Vice Shores PD and runs four jobs for the fixer Mama Lou across a living coastal city — traffic, pedestrians, a wanted level, missions, and a save — all playable offline in a desktop browser from static files.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. No build step, no network requests, no assets: the city, art and sound are all generated in code.
